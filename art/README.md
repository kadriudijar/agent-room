# Office artwork

Nine image sheets generated with the built-in image_gen tool. The complete prompts are in `prompts.json`.

These are visual drafts, not validated game atlases. The generator did not follow the exact logical pixel grid, output dimensions, flat palette, or uniform cell placement. Some shading and texture remain. Floor tiles have margins and are not seamless. Boss and intern seated frames include desks and chairs, and shirts are not uniformly pure magenta. The first desk monitor incorrectly contains code instead of being off; animation pairs are not exact pixel shifts. UI panels are not validated nine-slices. Accessories and icons need precise registration and scaling.
